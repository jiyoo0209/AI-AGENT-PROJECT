# AI 프로젝트매니저 (AI-AGENT-PROJECT)

역할별 AI 에이전트가 하나의 개발팀처럼 일하는 Android 앱입니다. 사용자는 최종 책임자(대표)이고, PM 에이전트가 요청을 작업으로 나눠 팀원에게 할당합니다. 계획은 대표가 승인한 뒤에 실행됩니다.

| 역할 | 하는 일 | 주요 산출물 | 기본 모델 |
|---|---|---|---|
| PM | 작업 분해 · 할당 · 취합 · 완료 보고 | 작업 계획 | Claude |
| 기획자 | 요구사항, 화면 정의 | 요구사항정의서.md, 화면설계서.md | Claude |
| 디자이너 | 디자인 계획 | 디자인계획서.md, 디자인시안_N.png | OpenAI |
| 퍼블리셔 | 디자인을 소스로 적용 | *.html (CSS 포함) | Claude |
| PL | 데이터 · 기술 설계 | 테이블정의서.csv, 기술설계서.md | Claude |
| 개발자 | 구현 | 소스 코드, 실행방법.md | Claude |
| 테스터 | 검증 | 테스트케이스.csv, 검수리포트.md | Claude |

역할마다 Claude와 OpenAI 중 어느 쪽을 쓸지, 어떤 모델을 쓸지 설정 화면에서 바꿀 수 있습니다.

## 설치 (APK)

1. 이 저장소의 **Releases**에서 가장 최근 빌드의 `AI-Agent-Project-N.apk`를 휴대폰으로 내려받습니다.
   (또는 **Actions** → 최근 실행 → Artifacts에서 내려받습니다. 이 경우 zip을 풀어야 합니다.)
2. 설치할 때 "출처를 알 수 없는 앱" 설치를 허용합니다.
3. 앱 **설정**의 **맥미니 서버**에 서버 주소와 토큰을 입력합니다. 맥미니에 로그인된 Claude Pro·ChatGPT Plus 구독으로 일하므로 API 요금이 들지 않습니다. 서버 설치는 [server/README.md](server/README.md)를 보세요. 서버 없이 쓰려면 Claude·OpenAI API 키를 입력합니다. 토큰과 키는 기기 보안 저장소에만 저장됩니다.

## 사용 흐름

1. 홈 화면에 만들고 싶은 것을 적고 **PM에게 맡기기**를 누릅니다.
2. PM이 작업 목록을 만들면 **승인하고 실행**을 누릅니다. 설정에서 "작업마다 승인"을 켜면 작업 하나가 끝날 때마다 멈춥니다.
3. 각 역할의 채팅방에서 결과를 확인하고, 파일 카드에서 **보기 / 공유 / 다운로드**를 합니다. 다운로드는 저장할 폴더(예: Download)를 고르면 그곳에 복사됩니다.
4. 채팅방에서 그 역할에게 직접 수정 요청을 보낼 수 있습니다. PM 채팅방에서 추가 작업을 요청하면 새 작업이 승인 대기로 올라옵니다.

모든 에이전트는 공통 맥락(요청, 계획, 지금까지의 산출물)을 읽고 일하므로, 다른 AI 회사 모델을 섞어 써도 산출물이 서로 이어집니다.

## 개발

```bash
npm install
npx tsc --noEmit        # 타입 검사
npx expo start          # 개발 서버
```

`main` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/build-apk.yml`)가 APK를 빌드해 Artifacts와 Releases에 올립니다. Actions 탭에서 **Run workflow**로 직접 실행할 수도 있습니다.

현재 APK는 디버그 키로 서명되어 있어 개인 설치용입니다. Play 스토어에 올리려면 별도 서명 키가 필요합니다.
